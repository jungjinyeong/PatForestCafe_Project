# 카운터

카운터는 특별 음료 주문 손님 구역과 일반 손님 구역으로 나뉜다.

카운터 도착 손님의 이벤트 흐름:
1. 디저트만 구입 → 자동 결제(기본음료 + 디저트) → 퇴장
2. 디저트 구입 → 특별 음료 주문(플레이어가 제작할 때까지 대기) → 자동 결제(특별음료 + 디저트) → 퇴장

- 특별 음료 주문 NPC는 특별 음료 주문 구역 도착 시 느낌표 아이콘 표시
- 결제 시 동전 아이콘 + 만족 아이콘 표시 후 퇴장
- 퇴장한 캐릭터는 테라스 공간으로 이동
- 게임 off 상태에서도 카운터 캐릭터 능력치(조리 속도/계산 속도)에 따라 코인 누적
  - 게임 시작 시 오프라인 수익 정산 및 획득 코인 알림 필요
