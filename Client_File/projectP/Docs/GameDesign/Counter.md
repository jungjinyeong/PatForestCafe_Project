# 카운터

스페셜 주문 기획은 삭제됨(2026-08) — 카운터는 더 이상 특별 주문 구역/일반 구역으로 나뉘지 않는다.

카운터 상호작용 지점(웨이포인트)은 카운터 가구가 아니라 그 자리에 고정 배치된 "주문받는 NPC"(바리스타/점원, `CharStaff`)에 붙는다. 손님(`CharNpc`)은 이 NPC에게 걸어가 자동 결제한다 — 실제 상호작용 로직은 웨이포인트 타입만 보고 동작하므로 소유자가 가구든 NPC든 동일하게 처리된다.

카운터 도착 손님의 이벤트 흐름:
1. 디저트 구입(선택) → 자동 결제(기본음료 + 디저트) → 퇴장

- 결제 시 동전 아이콘 + 만족 아이콘 표시 후 퇴장
- 퇴장한 캐릭터는 테라스 공간으로 이동
- 게임 off 상태에서도 카운터 캐릭터 능력치(조리 속도/계산 속도)에 따라 코인 누적
  - 게임 시작 시 오프라인 수익 정산 및 획득 코인 알림 필요
