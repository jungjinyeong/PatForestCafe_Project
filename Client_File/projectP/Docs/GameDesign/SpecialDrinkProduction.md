# 레시피 개발

- 스페셜 주문 기획은 삭제됨(2026-08) — 손님이 특정 음료를 지정해 대기하는 방식은 더 이상 없다.
- 대신 "레시피 개발북" 아이템을 소비해 레시피 개발 UI를 연다.
- 재료 테이블 목록을 보여주고, 선택 시 제작 화면에서 음료가 만들어지는 과정을 연출(이미지/이펙트/DOTween/애니메이션)하는 방식은 동일하게 유지.
- 목표 레시피를 미리 지정하지 않는다 — 선택한 재료 조합이 아직 발견하지 못한 레시피와 일치하면 자동으로 발견 처리된다(레시피 도감에 등록).
- 손님에게 전달하는 개념이 아니므로 완료 시 골드 보상은 없음(순수 진행도/도감 확장 요소).
- 레시피 개발북 획득 경로는 아직 미정(추후 논의).
