# 커피머신 제작 + 둘기딜리버리

- 스페셜 주문(손님이 특정 음료를 지정해 대기) 기획은 삭제됨(2026-08).
- 2026-09: UI 시안(ForestCafe UI Lab "제작/커피머신")을 기준으로 커피머신 제작 화면 + 둘기딜리버리(배달 주문)로 개편.

## 화면 구성
- 좌측 레시피 목록: 레시피 도감에 발견된 음료만 표시. 누르면 기본 재료 슬롯이 자동으로 채워지고 온도도 맞춰진다.
- [둘기딜리버리] 버튼으로 배달 팝업(UI_Popup_Delivery: 주문서 최대 3장 + 픽업대 3칸 + 배달 벨/폐기)을 연다.
- HOT / ICE 토글.
- 기본 재료 슬롯 5칸 / 커스텀 재료 슬롯 5칸. 슬롯을 누르면 재료 선택 모달(남은 수량 = 보유 − 슬롯에 넣은 수량).
- 우측 정보: 컵 미리보기(HOT 머그 / ICE 유리컵), 기본·커스텀 재료 속성, 제작하기.
- 제작 결과 팝업: 성공 "OO 완성!" / 실패 "음… 실패한 음료" → [픽업대로 이동] / [폐기].

## 제작 규칙
- 기본 재료(얼음 제외) 조합 + 온도로 Drink 테이블을 매칭한다.
- 얼음은 재료 목록에 나오지 않고, ICE 음료 제작 시 레시피에 적힌 개수만큼 자동 소모된다.
- 커스텀 재료는 레시피 매칭에 영향을 주지 않고, 음료 속성과 주문 토핑 요청 판정에만 쓰인다.
- 제작 시 재료(+얼음)는 성공/실패와 무관하게 소모된다.
- 커피머신에서는 도감에 발견된 레시피만 제대로 만들어진다. 미발견 조합은 "실패한 음료"(얼음 미소모) — 발견은 가공섬 레시피 연구소에서.

## 레시피 연구소 (가공섬, UI_Popup_RecipeLab)
- 진입: 가공섬의 [레시피 연구소] 건물에서만. (로비의 커피머신/도감 개발 버튼은 제거)
- 연구소 직원 꾸리(너구리)가 조합을 분석해 준다. 이미 개발한 조합을 올려 두면 미리 알려 준다.
- 연구 재료 5칸 + HOT/ICE로 조합을 정하고 [개발하기] → 확인 → 분석 연출(약 2초) → 결과.
- 조합이 아직 발견하지 않은 레시피와 일치할 때만 레시피 개발권(아이템 1002) 1장 + 재료(+ICE 레시피 얼음)를 소모하고 도감에 등록한다.
- 결과
  - 새 레시피: "짜잔! 새로운 레시피를 발견했어요!" → 완성 음료를 [픽업대로 이동] / [폐기].
  - 이미 발견: "OO은(는) 이미 등록된 레시피예요." (소모 없음)
  - 일치 없음: "아직 레시피를 발견하지 못했어요." (소모 없음)
- 개발권이 없으면 개발을 시작할 수 없다. 재료가 부족하면 안내만 하고 소모하지 않는다.
- 우측 "오픈된 레시피" 목록으로 발견한 레시피를 확인한다(같은 조합을 다시 시도하지 않도록).
- [?] 도움말 2페이지.
- 레시피 개발권 획득 경로는 아직 미정.

## 둘기딜리버리
- 주문은 도감에 발견된 음료 중 DrinkRequest 가중치로 생성된다(발견 레시피가 없으면 주문도 없음).
- 주문에는 추가 요청이 확률로 붙는다: 토핑 추가(토핑 가능 재료), 포함 속성, 제외 속성.
- 배달 조건: 주문 음료(온도 포함)와 픽업대 음료가 같아야 한다. 실패한 음료는 배달 불가(폐기만 가능).
- 보상: 메뉴 가격(MenuItem.Price) × (1 + 충족한 토핑/포함 요청 수 × 0.2 − 제외 속성을 넣었으면 0.2) 골드.
  - 제외 속성은 레시피대로 만들면 항상 지켜지므로 보너스가 아니라 어겼을 때만 감점.
- 픽업대가 가득 차면 제작할 수 없다(완성 음료를 잃지 않도록).
- 배달 후 20초 뒤 빈 주문 자리가 보충된다.
- 주문서와 픽업대 음료는 세이브에 저장된다.

## 임시 수치 (기획 확정 필요)
| 항목 | 값 | 위치 |
|---|---|---|
| 주문 보충 대기 | 20초 | `DeliveryModel+Ctrl.ORDER_REFILL_SECONDS` |
| 토핑 요청 확률 | 40% | `TOPPING_REQUEST_CHANCE` |
| 포함 속성 요청 확률 | 35% | `INCLUDE_TAG_REQUEST_CHANCE` |
| 제외 속성 요청 확률 | 30% | `EXCLUDE_TAG_REQUEST_CHANCE` |
| 요청 1개당 보너스 | +20% | `BONUS_RATE_PER_REQUEST` |
| 재료 속성/설명/토핑 여부 | 임시 입력 | `CSV/DrinkMaterial.csv` Tags / Desc / IsTopping |
