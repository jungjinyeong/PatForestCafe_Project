# 오븐 제작 (빵)

- 2026-09: 재료 조합을 맞히면 즉시 1개 생산하던 방식 → UI 시안(ForestCafe UI Lab "제작/오븐") 기준 **트레이 굽기** 방식으로 개편.
- 진입: 가공섬 [bread product] 건물 → 팝업 `UI_Popup_BreadProduction`(오븐 제작).

## 흐름
1. 트레이를 눌러 **반죽 설정**: 발견한 빵 레시피 선택 → 기본 재료가 레시피 재료(하급)로 채워짐.
2. 기본 재료 칸을 누르면 **같은 분류 안에서만** 등급(하급/중급/고급)을 바꿀 수 있다.
3. 추가 재료 5칸(아무 빵 재료)은 속성만 더한다(현재 판매가/보관 영향 없음 — 효과 미정).
4. 제작 수량(MIN −10 −5 −1 +1 +5 +10 MAX, MAX = 오븐 레벨 한도) → [트레이에 반죽 저장].
5. [굽기 시작하기]: 설정된 **모든 트레이의 재료(기본+추가 × 수량)를 합산해 한 번에 차감**. 부족하면 시작 불가.
6. 굽기 시간 뒤 완성 빵이 **창고(빵 재고)에 품질별로 자동 보관**된다. 팝업을 닫거나 앱을 꺼도 진행되며, 다시 켜면 완료분이 보관된다.

## 품질
- 재료 등급: BreadMaterial.csv `Grade` (1=하급 2=중급 3=고급), 같은 `Category`끼리 교체.
- 완성 품질 = 기본 재료 등급 **평균 반올림** (예: 황금 밀가루(고)+버터(하)+설탕(하)+고급 우유(고) → 2.0 → 중급).
- 판매가 배율: 하급 1.0 / 중급 1.2 / 고급 1.5 (임시). 손님 결제 = 메뉴 가격 × 품질 배율 × 결제 수익 업그레이드 배율.
- 진열대에 빵을 올리면 창고 재고에서 **높은 품질부터** 꺼낸다.

## 레시피
- 반죽 설정에는 **발견한 빵 레시피만** 나온다(레시피 도감 공용).
- 기본 발견: `ConfigData.DefaultBreadRecipeTid` = 20002(식빵).
- 나머지: 상점가 찍찍이 [빵 레시피] → `UI_Popup_BreadRecipeShop`에서 골드로 구매(Bread.csv `RecipePrice`).

## 오븐 레벨 (임시, 코드 상수 `OvenModel+Ctrl`)
| 레벨 | 트레이 | 트레이당 최대 수량 | 굽기 시간 | 다음 레벨 비용 |
|---|---|---|---|---|
| 1 | 2 | 10 | 15초 | 500 G |
| 2 | 3 | 20 | 12초 | 1,500 G |
| 3 | 3 | 30 | 10초 | - |
- 업그레이드: 상점가 똘이 [시설 업그레이드] 팝업의 "오븐" 영역.

## 재료 획득
- 재료 상점(상점가 찍찍이 [재료 구입]): 등급별 빵 재료 전부 판매(중급 ×2, 고급 ×4 가격).
- 빵 미니게임: 보상 등급 확률 하급 70% / 중급 25% / 고급 5% (임시).

## 기타
- 왼쪽 퀘스트 목록은 더미(퀘스트 시스템 없음).
- 빵 재고 패널: 창고 1/2 탭(6종씩), 항목을 누르면 설명·속성·품질별 수량.
- 구 세이브(품질 없는 빵 재고)는 로드 시 전부 하급으로 이관.
