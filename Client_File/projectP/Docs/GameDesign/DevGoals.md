# 개발 목표

## 1. 제작
- 재료를 선택하여 조합하면 즉시 결과물을 확인할 수 있는 직관적인 조리 시스템
- 다양한 재료 조합을 통해 새로운 음료와 디저트 제작
- 레시피 도감을 채우는 수집 재미

## 2. 운영
- 가공섬에서 재료를 수급하고 제작에 활용
- 제작한 메뉴를 진열하고 판매하거나 손님 주문을 처리하여 수익 창출
- 업그레이드를 통해 생산성과 수익 향상
- 플레이어가 자신만의 운영 방식을 만들어갈 수 있도록 설계

## 3. 게임 플레이 방향
- 복잡한 시스템이나 과도한 학습 없이 누구나 쉽게 즐길 수 있도록 설계
- 특별한 공략 없이도 자연스럽게 진행되는 구조 지향
- 타임오버, 에너지 소모, NPC의 부정적 반응 등 스트레스 요소 최소화
