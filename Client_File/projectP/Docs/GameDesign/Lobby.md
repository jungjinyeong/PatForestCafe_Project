# 게임 로비

- '복슬복슬 온천탕'처럼 NPC가 정해진 구역에서 자유롭게 이동하며, waypoint별로 이벤트 발생
- 가구는 그리드 기반 스냅 시스템으로 자유 배치 가능
- 기본 등록 음료 존재. 스페셜 주문 기획은 삭제됨(2026-08) — 손님이 특정 음료를 요구하지 않으며, 대신 플레이어가 "레시피 개발북"을 소비해 새 레시피를 개발/도감에 등록하는 방식으로 대체
- NPC는 출입구 등장 → 매장을 돌아다니며 디저트 선택 → 카운터로 이동

## 층 구성 (2026-10-12 변경)

로비는 **매장층 4개 + 테라스층 3개 = 7층**이다. 아래에서 위로 B3 · B2 · B1 · 1F · T1 · T2 · T3.

| 층 | 종류 | 해금 순서 | 해금 비용(가안) |
|---|---|---|---|
| 1F | 매장 | 기본 개방 | - |
| B1 | 매장 | 1 | 500 G |
| B2 | 매장 | 2 | 1,000 G |
| B3 | 매장 | 3 | 2,000 G |
| T1 | 테라스 | 기본 개방 | - |
| T2 | 테라스 | 1 | 4,000 G |
| T3 | 테라스 | 2 | 8,000 G |

- 시작 시 1F와 T1이 열려 있다. 매장층(1F→B1→B2→B3)과 테라스층(T1→T2→T3)은 **각각 따로** 해금한다.
- 손님은 열린 매장층 중 한 곳에 들어와 빵을 사고 결제한 뒤, **열린 테라스층 중 무작위 한 곳**에 잠시 머물다 퇴장한다.
- 순서·비용은 `Assets/CSV/Floor.csv`에서 바꾼다.
  - `Tid`: 층 ID(아래→위 1~7). 씬의 `WaypointGroup.Order`와 같아야 한다.
  - `Name`: 화면 표시 이름(층 이동 버튼, 해금 팝업).
  - `FloorType`: 0=매장, 1=테라스.
  - `UnlockOrder`: 0=기본 개방. 같은 종류 안에서 작은 수부터 하나씩 해금.
  - `UnlockCost`: 해금 비용(골드).
- 층 해금 팝업(`UIFloorUnlock`)은 매장/테라스 두 줄로 나뉜다. 진입: 로비 [층 언락] 또는 상점가 똘이 [층별 설비].
- 구 세이브(B2가 Order 1이던 6층 구성)는 불러올 때 층 ID를 +1로 옮긴다(`SaveManager.MigrateFloorLayout`).

## 보유 가구 (2026-10-12 변경)

- 가구를 사면 **보유 수**가 1 늘고, 바로 배치 모드로 나온다. 가구는 **팔 수 없다**.
- **보관 중** = 보유 수 − 배치된 수. 로비 [배치] 목록에서 보관 중인 가구는 가격 대신 「보관 n」으로 보이고, 누르면 골드 없이 꺼내 놓는다. 보관 중인 게 없으면 골드로 산다.
- 상점가 똘이 [가구 구입]은 항상 골드로 새로 산다(보관 수가 있으면 목록에 함께 표시).
- [리셋]: 배치된 가구를 모두 치우고 보관 중으로 돌린다(판매·환불 없음).
- 새로 놓던 가구를 [취소]하면 보관 중으로 남는다(골드 환불 없음).
- 세이브: `SaveData.OwnedFurniture`. 이 기록이 없던 구 세이브는 배치된 가구 수만큼 보유한 것으로 채운다.
