# 도감

- 2026-09: 음료 이름만 나열하던 목록 → UI 시안(ForestCafe UI Lab 메인 "레시피 북") 기준 **책 형태 도감**으로 개편.
- 명칭은 **도감**으로 통일한다("레시피 북"은 "레시피 개발북" 아이템과 헷갈림). 코드: `UIPopupCollection`, 프리팹 `UI_Popup_Collection`.
- 진입: 로비 하단 [도감].

## 구성
- **왼쪽 페이지**: 분류 탭 `전체 / 음료 / 디저트`(탭마다 발견 수/전체 수), 장 제목 + "발견 n / m", 레시피 목록.
  - 행: 도감 번호(음료 Tid 순 → 디저트 Tid 순, 01부터), 썸네일(MenuItem Atlas/Icon), 분류, 이름, 발견 상태.
  - 미발견 레시피도 목록에 나오며 이름은 `???`.
- **오른쪽 페이지**: 선택한 레시피 상세.
  - 책갈피(발견/미발견), `RECIPE 번호`, 이름, 분류 도장(음료는 `음료 | ICE/HOT`), 그림, **오늘의 기록**, **INGREDIENTS**(재료 이름 + 보유 수량).
  - 오늘의 기록: 디저트 = Bread.csv `Desc` + 속성, 음료 = 설명 컬럼이 없어 "온도 + 종류 + 재료 속성"으로 자동 생성.
  - 미발견: 이름·재료 이름을 가리고(재료 개수만 표시) 획득 방법을 안내(음료 = 가공섬 레시피 연구소, 디저트 = 상점가 찍찍이 레시피 구매).
- 시안의 **리소스 확인 도구**(안전영역/표시 배율)와 **재료 표본(32×32 아이콘)** 은 구현하지 않음(재료 아이콘 리소스 없음).
